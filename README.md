# Todo Management System 📝

A robust, full-stack Todo Management System built with ASP.NET Core MVC. This application allows users to securely register, log in, and manage their daily tasks efficiently. It is designed with a focus on clean architecture, loosely coupled components using Dependency Injection, and data isolation.

## ✨ Features
* **User Authentication:** Secure registration and login system utilizing ASP.NET Core Identity.
* **Task Management:** Full CRUD (Create, Read, Update, Delete) operations for daily todos.
* **Dependency Injection:** Loosely coupled, testable, and maintainable architecture utilizing ASP.NET Core's built-in DI container.
* **Data Isolation:** Users can only view and modify their own tasks; complete privacy between accounts.
* **Responsive UI:** Clean, modern, and user-friendly interface.

## 🛠️ Tech Stack
* **Backend:** C#, ASP.NET Core MVC
* **Database:** SQL Server, Entity Framework Core (Code-First Approach)
* **Authentication:** ASP.NET Core Identity
* **Architecture:** Dependency Injection (DI)
* **Containerization:** Docker (Used for hosting the SQL Server database)
* **Development Environment:** Visual Studio Code on macOS
